# fc — language spec & reimplementation suite

This directory is the source of truth for **what the fc language *means*** —
independent of the current implementation (the JS in `../index.html`) — so the
language can be frozen, tested, and reimplemented (Rust → WASM) as a single core
for web + native.

## Files
| File | What it is |
|---|---|
| `GRAMMAR.md` | The **syntax** (descriptive EBNF). Heuristic spots tagged `[QUIRK]`. Must be frozen by the corpus. |
| `SEMANTICS.md` | The **runtime** — where fc's meaning actually lives (`==`, truthiness, the if/else-in-loop divergence, magic globals, tags, singularize, no-params/no-hoist, NET identity). |
| `CONFORMANCE.md` | The harness contract: capture surface, determinism (seeded RNG), comparison rules. |
| `corpus/*.fc` | Seed test programs targeting the high-divergence cases. **Use `X is Y` assignment** (not `set` — `set` is a silent no-op call). |
| `corpus/_goldens.json` | **Real** captured outputs `{say, errors, vars}` from the live interpreter. The regression net. |
| `port/fc_core.rs` | Rust port skeleton (Value/AST/Host/Runtime). **No parser yet.** |
| `MODULARIZATION.md` | Plan to split the monolith into `lang/`+`platform/`+`ui/` and rebuild the single `index.html` via esbuild. |
| `WASM.md` | Command-buffer ABI + language ranking (Rust>Zig>AS>C>Go) + Rust→WASM spike plan. |

## How the goldens are generated (the oracle)
The interpreter's core isn't exposed (`window.runtime` is never set; `Runtime` is
class-scoped). A throwaway hooked copy adds `window.__fcRun(src, seed)` (builds a
fresh `Runtime`, parses, execs, returns `{say, errors, vars}`), served locally and
driven by Playwright. See `/tmp/pw2/conformance.js`. **Goldens come from execution,
never prediction.** When the `lang/` extraction lands, the same corpus runs in Node
by importing `parse`/`Runtime` directly (preferred — no browser, no drift).
